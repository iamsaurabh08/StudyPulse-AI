# 🎓 AI-Based Student Productivity and Study Planner

A modern, full-stack academic productivity suite and intelligent study scheduling platform engineered for university students. 

Designed for academic project demonstrations, this application dynamically balances subject difficulty ratings, upcoming exam deadlines, and daily study hours to create balanced study timetables, accompanied by task management, live progress analytics, ambient focus audio, and an AI study assistant.

---

## 🌟 Key Features

### 1. 📊 Modern Student Dashboard
* **Real-time Overview**: Quick-look KPI cards displaying total tasks, completed tasks, active pending tasks, urgent/today's deadlines, and total study hours.
* **Today's Action Items**: High-priority tasks surfaced directly with quick toggle checkboxes.
* **Progress Snapshot**: Visual completion percentage ring and progress bar computed dynamically from SQLite.
* **Daily Motivational Quotes**: Random quotes from notable scholars and thinkers (including Thiruvalluvar, APJ Abdul Kalam, Nelson Mandela) with an instant refresh button.

### 2. 🤖 AI & Rule-Based Study Planner
* **Multi-Factor Balanced Scheduling**: Computes time allocation using:
  * **Subject Difficulty**: 1 (Very Easy) to 5 (Very Hard).
  * **Exam Proximity / Urgency**: Higher weights automatically assigned to exams due within 48 hours to 10 days.
  * **Daily Availability**: Student-defined study hours per day.
* **Hybrid Intelligence Engine**:
  * **OpenRouter Generative AI**: Uses `deepseek/deepseek-r1:free` or specified models when an `OPENROUTER_API_KEY` is provided.
  * **Deterministic Heuristic Fallback**: A mathematical weighting algorithm that guarantees full functionality even with **no API key configured** or during network downtime.
  * **Transparent Attribution**: Badges clearly denote whether a timetable was generated by **AI** or the **Rule-Based Algorithm**.
* **Actionable Timetables**: Generates day-by-day structured sessions with specific study techniques (e.g., *Feynman Technique*, *Pomodoro 50/10*, *Active Recall*, *Past Paper Time Trials*) and scheduled rest intervals.
* **Exportable**: Built-in print/PDF-ready stylesheet.

### 3. 📋 Task Management (Full CRUD)
* **Create, Read, Update, Delete**: Complete task lifecycle management.
* **Rich Metadata**: Title, Subject, Priority (*Urgent*, *High*, *Medium*, *Low*), Deadline date, Duration in minutes, and Custom Notes.
* **Input Validation**: Strict validation prevents invalid submissions.
* **Search & Filters**: Live title/notes search and dropdown filtering by status (*Pending*, *Completed*) and subject.

### 4. 📈 Real-Time Progress Tracker
* **100% Real Database Analytics**: No simulated data. Percentages and counts are calculated directly via SQLite queries.
* **Subject-Wise Progress**: Per-subject breakdown displaying total tasks, completed tasks, allocated study hours, and individual progress bars.
* **Priority Distribution**: Visual breakdown showing task volume across urgency levels.

### 5. 👤 Student Profile & Preferences
* **Personalized Configuration**: Configure full name, email, university/institution, target exam, daily study availability, and preferred study time of day (*Morning*, *Afternoon*, *Evening*, *Night*).
* **Subject Enrollment**: Dynamically add and remove enrolled subjects.

### 6. 🎧 Focus Music & Study Ambient Sounds
* **Curated Database**: Embedded Spotify and YouTube audio streams categorized by:
  * **Mood**: *Focused* (Deep Concentration), *Calm* (Stress Relief), *Energetic* (Alertness), *Melancholy* (Late Night Focus).
  * **Language**: English and Tamil focus playlists.
  * **Style**: Lofi Hip Hop, Chill Pop, Soft Melody, Electronic Beats.

### 7. 💬 Academic AI Study Coach
* **Interactive Study Assistant**: Chat drawer for advice on overcoming procrastination, breaking down complex topics, and exam preparation strategies.
* **Offline Fallback Coach**: Provides structured academic guidance even when no external AI API key is configured.

```
D:\ZOYO\
├── backend/
│   ├── __init__.py           # Package marker

│   ├── planner.py            # AI & Priority-Weighted Rule-Based scheduling engines

│   ├── css/
│   │   └── style.css         # Modern dark-mode responsive UI
│   └── js/

│       └── app.js            # State management and DOM interaction controller
├── .env.example              # Environment variables template
├── requirements.txt          # Root Python dependencies
├── app.py                    # Root entry point
└── README.md                 # Project documentation
```

* **Frontend**: HTML5, Modern CSS3 (Grid/Flexbox/CSS Variables), Vanilla JavaScript (ES6+ async/await, relative API routing for production).
* **Backend**: Python 3.12, Flask 3.x, `gunicorn>=21.2.0`, `flask-cors`, `python-dotenv`, `requests`.
* **Database**: Embedded SQLite3 with WAL mode for zero-configuration, reliable persistence (customizable via `DATABASE_PATH`).
* **AI Service**: OpenRouter API (`deepseek/deepseek-r1:free`) with local deterministic heuristic fallback.

## 🌐 Public Cloud Deployment Guide

The application is fully deployment-ready for popular cloud platforms such as **Render**, **Railway**, **Fly.io**, **Heroku**, or any Linux VPS.

### A. Deploy to Render (Recommended - Free Web Service)

1. **Push your code to GitHub / GitLab**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for StudyPulse AI"
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. **Create a New Web Service on Render**:
   * Go to [Render Dashboard](https://dashboard.render.com/) and click **New + > Web Service**.
   * Connect your GitHub repository.
3. **Configure Settings**:
   * **Name**: `studypulse-ai` (or your choice)
   * **Environment**: `Python 3`
   * **Region**: Choose closest to your audience (e.g., Oregon, Frankfurt, Singapore)
   * **Branch**: `main`
   * **Build Command**:
     ```bash
     pip install -r requirements.txt
     ```
   * **Start Command**:
     ```bash
     gunicorn app:app
     ```
4. **Environment Variables**:
   Under the **Environment Variables** tab, configure:
   * `PORT`: Automatically set by Render (the app automatically reads `PORT` from environment).
   * `FLASK_DEBUG`: `0`
   * `OPENROUTER_API_KEY`: *(Optional)* Your OpenRouter key, or leave blank to run the offline rule-based heuristic scheduler.
   * `SITE_URL`: `https://<your-render-subdomain>.onrender.com`
5. **Persistent Disk (Optional for SQLite persistence across redeploys)**:
   * Under **Disks**, add a disk mount at `/var/data` (1 GB is plenty).
   * Add environment variable: `DATABASE_PATH=/var/data/study_planner.db`.

---

### B. Deploy to Railway

1. Go to [Railway Dashboard](https://railway.app/).
2. Click **New Project > Deploy from GitHub repo**.
3. Select your repository.
4. Railway will automatically detect the Python environment, `Procfile`, and `requirements.txt`.
5. Under **Variables**, add:
   * `PORT`: `5000` (or Railway's dynamic `$PORT`)
   * `FLASK_DEBUG`: `0`
   * `OPENROUTER_API_KEY`: *(Optional)*
6. Click **Deploy**. Under **Settings > Networking**, generate a public domain (e.g., `studypulse-production.up.railway.app`).

---

### C. Deploy to Linux VPS (Ubuntu/Debian with Gunicorn & Systemd)

1. **Clone repository and setup virtual environment**:
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git /var/www/studypulse
   cd /var/www/studypulse
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
2. **Create Systemd Service (`/etc/systemd/system/studypulse.service`)**:
   ```ini
   [Unit]
   Description=StudyPulse AI Gunicorn Application Server
   After=network.target

   [Service]
   User=www-data
   Group=www-data
   WorkingDirectory=/var/www/studypulse
   Environment="PATH=/var/www/studypulse/venv/bin"
   Environment="PORT=5000"
   Environment="FLASK_DEBUG=0"
   ExecStart=/var/www/studypulse/venv/bin/gunicorn -c gunicorn.conf.py app:app
   Restart=always

   [Install]
   WantedBy=multi-user.target
   ```
3. **Start and Enable Service**:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl start studypulse
   sudo systemctl enable studypulse
   ```
4. **Nginx Reverse Proxy (`/etc/nginx/sites-available/studypulse`)**:
   ```nginx
   server {
       listen 80;
       server_name yourdomain.com www.yourdomain.com;

       location / {
           proxy_pass http://127.0.0.1:5000;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_set_header X-Forwarded-Proto $scheme;
       }
   }
   ```
5. Enable and reload Nginx:
   ```bash
   sudo ln -s /etc/nginx/sites-available/studypulse /etc/nginx/sites-enabled/
   sudo nginx -t && sudo systemctl reload nginx
   ```

## 🚀 Quick Start Guide (Windows)

### 1. Prerequisites
* Python 3.12 (Recommended; Python 3.12.10+ installed)
* A modern web browser (Chrome, Edge, Firefox)

### 2. Setup Virtual Environment
Open PowerShell or Command Prompt in the project directory:

```powershell
cd D:\ZOYO

# Create a virtual environment using Python 3.12
python -m venv venv

# Activate the virtual environment
.\venv\Scripts\Activate.ps1
# (Or in cmd.exe: .\venv\Scripts\activate.bat)
```

### 3. Install Dependencies
```powershell
pip install -r requirements.txt
```

### 4. Configure Environment Variables (Optional)
Copy the example environment file:
```powershell
Copy-Item .env.example .env
```
* If you have an OpenRouter API key, add it to `.env`:
  ```ini
  OPENROUTER_API_KEY=sk-or-v1-...
  OPENROUTER_MODEL=deepseek/deepseek-r1:free
  ```
* If you **do not** have an API key, leave it blank. The system will automatically use the built-in **Rule-Based Heuristic Scheduling Engine**.

### 5. Run the Application
You can run the server directly from the root directory:
```powershell
python app.py
```
*(Or via `python backend/app.py`)*

### 6. Access the Application
Open your web browser and navigate to:
```
http://localhost:5000
```

## 📡 API Endpoints Reference

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/status` | System health, AI key configuration state, and active mode |
| `GET` | `/api/profile` | Retrieve student profile details |
| `POST` | `/api/profile` | Update student profile details and subjects |
| `GET` | `/api/tasks` | List tasks (supports `?status=pending\|completed&subject=...&search=...`) |
| `POST` | `/api/tasks` | Create a new study task |
| `PUT` | `/api/tasks/<id>` | Update an existing task |
| `PATCH` | `/api/tasks/<id>/toggle` | Toggle task completion status |
| `DELETE` | `/api/tasks/<id>` | Delete a task |
| `GET` | `/api/analytics/progress` | Live progress metrics, completion rates, and subject breakdown |
| `POST` | `/api/planner/generate` | Generate timetable using AI or Priority-Weighted Rule-Based Engine |
| `GET` | `/api/planner/active` | Get currently active study timetable |
| `GET` | `/api/planner/history` | Get recent timetable generation history |
| `POST` | `/api/assistant` | AI Study Assistant query endpoint with offline coach fallback |
| `POST` | `/api/music-suggest` | Spotify & YouTube playlist recommendations by mood/genre |
| `GET` | `/api/quote` | Fetch a random motivational study quote |
